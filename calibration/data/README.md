# Experimental testing of VHB 4910

The CSV data files in this respository have been obtained from [[1]](#1) with the help of the tool described in [[2]](#2).
The experiments are gathered in two different datasets, depending on the experiment type.

## Quasi-static loading

The experiments contained in the quasi-static dataset have the following fields:
- id
- stretch
- stress

[](assets/relaxation.png)

## One-cycle loading-unloading

The experiments contained in the cyclic loading dataset have the following fields:
- id
- stretch
- stress
- rate

[](assets/stretch%201.5.png)
